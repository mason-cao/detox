# Detox web — Cloudflare Pages runbook

The static dashboard (`web/`) is published as a Cloudflare Pages project at `app.detox.app`. There is no bundler — Pages serves the HTML/CSS/JS straight from the repo. Per-environment values (Supabase keys, the Railway api base) are injected at deploy time via `web/config.js`, generated by `infra/cloudflare/build.sh`.

## One-time setup

1. **Create the Pages project.**
   In the Cloudflare dashboard: **Workers & Pages → Create → Pages → Connect to Git** and link the GitHub repo.

2. **Build settings.**

   | Field | Value |
   |---|---|
   | Production branch | `main` |
   | Build command | `infra/cloudflare/build.sh` |
   | Build output directory | `web` |
   | Root directory | (leave empty — repo root) |

3. **Environment variables.**
   Under **Settings → Environment variables → Production** add:

   - `DETOX_SUPABASE_URL` — `https://<project>.supabase.co`
   - `DETOX_SUPABASE_ANON_KEY` — Supabase anon (public) key
   - `DETOX_API_BASE` — `https://api.detox.app`

   Mirror the same set under **Preview** if you use preview deployments.

4. **Custom domain.**
   **Settings → Custom domains → Set up a custom domain** → `app.detox.app`. Cloudflare provisions the TLS cert. Make sure `api.detox.app` is also a CNAME pointing at the Railway service so the web client and the api share a registrable domain (helps with cookie/CORS).

## How config injection works

- At build time the Pages runner executes `infra/cloudflare/build.sh`, which writes `web/config.js`:

  ```js
  window.DETOX_SUPABASE_URL = "...";
  window.DETOX_SUPABASE_ANON_KEY = "...";
  window.DETOX_API_BASE = "https://api.detox.app";
  ```

- `web/index.html`, `web/sign-in.html`, and `web/pair.html` load `/config.js` before `auth.js`, so Auth boots with the right cloud target on first paint.

- Locally, `web/config.js` is gitignored. The Flask agent serves the same shape dynamically at `/config.js` (see `agent/server.py`) so dev parity is preserved without a build step.

## CORS

The Railway api allows `https://app.detox.app` via `API_CORS_ORIGINS`. If you use a Cloudflare preview domain (`*.detox-app.pages.dev`), add it to the same list, otherwise the browser will refuse to call `/v1/*`.

## Smoke test

From a real browser — ideally a phone — after the first deploy:

- `https://app.detox.app/` redirects to `/sign-in.html` while signed out.
- Magic-link sign-in lands you on `/`. Today's data pulled from the Railway api shows up.
- `/pair.html` shows a 6-character code; running `python3 -m agent.cli.pair` on the Mac and pasting the code flips the page to "✓ paired".
- DevTools → Network shows `Authorization: Bearer …` on every `/v1/*` call, and CORS preflight succeeds.
